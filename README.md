# GitPoulpi Homebrew tap

[Homebrew](https://brew.sh) tap for [GitPoulpi](https://github.com/Poulpi-Lab/GitPoulpi), a lightweight cross-platform terminal Git client (macOS and Linux).

```sh
brew tap poulpi-lab/gitpoulpi
brew install gitpoulpi
```

Update with `brew upgrade gitpoulpi`. The formula in `Formula/` is written by the GitPoulpi release workflow; do not edit it by hand.
